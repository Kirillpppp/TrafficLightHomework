# Домашнее задание: светофор (самостоятельный проект)

Это **новый самостоятельный проект C++**, без каких-либо банковских карт и зависимостей от предыдущих практик.

## Содержание

- `TrafficLight.h` — `Address` (страна, город, улица, координаты), `TrafficLightsState` (`RED`, `YELLOW`, `GREEN`), объявление класса `TrafficLight`.
- `TrafficLight.cpp` — реализация `GetCurrentState()` и `GetInfo()` с цветным консольным выводом.
- `main.cpp` — создание светофора и бесконечный цикл `while (true)` с `sleep_for(23000ms)`.
- `TrafficLightHomework.slnx` и `TrafficLightHomework.vcxproj` — решение и проект Visual Studio.

## Запуск

1. Распакуйте архив в отдельную папку.
2. Откройте `TrafficLightHomework.slnx` в Visual Studio. Если ваш Visual Studio не поддерживает `.slnx`, откройте `TrafficLightHomework.vcxproj`.
3. Выберите `Debug | x64`. Выполните **Сборка → Перестроить решение**.
4. Запустите `Ctrl+F5`.
5. Остановите бесконечный цикл сочетанием **Ctrl+C** в консоли.

Проект настроен на **C++20** и toolset **v145**, как в вашем исходном файле Visual Studio. Если Visual Studio пишет, что набор средств `v145` не установлен, выполните «Перенацелить решение» / установите подходящий toolset в свойствах проекта.

Сборка вне Visual Studio:

```sh
g++ -std=c++20 -Wall -Wextra -pedantic main.cpp TrafficLight.cpp -o TrafficLightHomework
./TrafficLightHomework
```

## Логика светофора

| Секунды минуты | Цвет |
|---|---|
| 00–05 | жёлтый |
| 06–30 | зелёный |
| 31–35 | жёлтый |
| 36–59 | красный |

Это **учебное расписание**, не соответствующее фактической работе светофора в Токио. Тестовый адрес: Япония, Токио, перекрёсток Сибуя (Shibuya Crossing), координаты `35.6595, 139.7005`. Цвет определяется по секундам времени компьютера.

Обновление экрана происходит **каждые 23 секунды**, как требуется в задании. Поскольку интервал обновления равен 23 секундам, программа отображает снимки состояния и может не показать каждую промежуточную смену цвета между ними.
