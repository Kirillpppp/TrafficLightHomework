# Домашнее задание: светофор (самостоятельный проект)


## Содержание

- `TrafficLight.h` — `Address` (страна, город, улица, координаты), `TrafficLightsState` (`RED`, `YELLOW`, `GREEN`), объявление класса `TrafficLight`.
- `TrafficLight.cpp` — реализация `GetCurrentState()` и `GetInfo()` с цветным консольным выводом.
- `main.cpp` — создание светофора и бесконечный цикл `while (true)` с `sleep_for(23000ms)`.
- `TrafficLightHomework.slnx` и `TrafficLightHomework.vcxproj` — решение и проект Visual Studio.
